# Security Education Lab (Cyber Kill Chain Demo)

このリポジトリは、セキュリティ教育やデモンストレーションを目的として、意図的に脆弱性を組み込んだ仮想環境（VM）の構築コードと、その攻撃シナリオ・解説資料をまとめたものです。

単なる「脆弱なWebアプリ」ではなく、**サイバーキルチェーン（偵察〜内部探索〜権限昇格）** という攻撃の全体像をハンズオンで学ぶための環境として設計しています。

## 🎯 プロジェクトの目的とアピールポイント

1. **攻撃者の思考プロセスの体系化**
   - nmap や gobuster を用いた**偵察・列挙**から始まり、**OSコマンドインジェクション**による初期侵入、さらに設定ミス（cron）を突いた**権限昇格**へのシナリオを構築しています。
   - 単発の脆弱性を突くだけではなく、「なぜその脆弱性が生まれるのか」「攻撃者はどうやって次のステップへ進むのか」を解説できる構成にしています。

2. **IaC (Infrastructure as Code) による再現性と隔離**
   - ホストOSから完全に隔離された `libvirt` ネットワーク上で安全に検証できるポリシーを適用しています。
   - Vagrant と Chef を用いて構築を自動化しています。

3. **教育用ドキュメントの整備**
   - セキュリティ初学者向けに、「攻撃手順」だけでなく「どうすれば防げたのか（多層防御の視点）」を重視したスライド構成案や手順書を作成しています。

## 📝 環境構築（IaC）に関する注記

本環境は、Rapid7社が提供する教育用VM `metasploitable3` (Ubuntu 14.04 版) をベースイメージとして利用しています。
そのため、本リポジトリには Metasploitable3 の巨大なソースコード全体を含めるのではなく、**本デモシナリオのために独自に追加・修正した IaC コード（Vagrantfile, Chef Recipes）とアプリケーションコード（src/）の差分のみ**を抽出して配置しています。
（※実際に環境をゼロから構築する場合は、公式リポジトリに対して本リポジトリの差分コードをマージしてビルドする構成を想定しています。）

## 📁 ディレクトリ構成

* `docs/`: システムの構成図、デモの安全ポリシー、スライドのアウトラインなど。
* `demos/`: デモの具体的な進行手順書（README.md）と、使用するワードリスト。
* `src/web_app/`: OSコマンドインジェクションのデモ用として意図的に脆弱に実装された PHP アプリケーション。
* `infrastructure/`: VM構築用の `Vagrantfile` と、独自カスタマイズ用（不要なサービスの停止、SSHユーザーの整理、cron権限昇格用設定など）の Chef レシピ。

## 🛠 使用技術・ツール

* **インフラ構築**: Vagrant, libvirt (KVM), Chef
* **ゲストOS**: Ubuntu 14.04 (Metasploitable3 Base)
* **Webスタック**: Apache, PHP 5.4.5, MySQL
* **デモ/攻撃ツール**: nmap, gobuster, curl, netcat

## 🛡️ 学習できる攻撃シナリオ（キルチェーン）

1. **Reconnaissance (偵察)**: `nmap` による不要な開口部（ポート）の調査。
2. **Enumeration (列挙)**: `gobuster` を用いた、隠された管理画面やログインフォームの発見。
3. **Exploitation (攻撃の実行)**: ログインフォーム（PHP）に存在する「入力値のOSコマンドへの直接連結」を利用した、OSコマンドインジェクションの実行。
4. **Command & Control (C2/遠隔操作)**: コマンドインジェクションを利用したリバースシェルの確立。（※デモ内では概念説明として実施）
5. **Privilege Escalation (権限昇格)**: Webサーバ権限（`www-data`）での内部探索により、rootが定期実行するcronスクリプトの権限設定ミスを発見。
